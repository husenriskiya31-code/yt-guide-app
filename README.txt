APK ለመገንባት (ምንም ሳይጭኑ — በነጻ):
1. github.com ላይ አዲስ repository ይፍጠሩ፤ የዚህን አቃፊ ፋይሎች (ከ .github አቃፊ ጋር) ይጫኑ።
2. Actions ትር → "Build APK" → ሲጨርስ Artifacts ውስጥ yt-guide-apk ያውርዱ።
3. app-release.apk ን ወደ ስልክ ልከው ይጫኑ ("Install unknown apps" ፍቀዱ)።
በኮምፒውተር ላይ ከሆነ፦ flutter create . --platforms=android && flutter build apk --release
